== Virtual Machine doesn't start ==
Error: VirtualBox can't enable the AMD-V extension. Please disable the KVM kernel extension, recompile your kernel and reboot (VERR_SVM_IN_USE). Result Code: NS_ERROR_FAILURE (0X80004005) Component: ConsoleWrap Interface: IConsole {6ac83d89-6ee7-4e33-8ae6-b257b2e81be8}

frees the AMD-V (SVM) hardware virtualization feature, so that other programs—like VirtualBox—can use it.
- KVM (via kvm_amd) normally controls AMD-V.
- If it’s loaded, VirtualBox cannot access AMD-V.
- Removing the module temporarily allows VirtualBox to use AMD-V.

sudo rmmod kvm_amd
